PART 2B - Project folder + tools on the GPU computer (from an empty disk)

BEFORE YOU START: what you are building in this part

You now have an empty GPU computer. In this part you create the QueryMesh folder structure by hand, learn the ONE procedure you will use to create every file in this manual, install the tools (tmux, uv, Python 3.12, the AWS CLI, FakeCloud), create the Python environment, store your secrets in a .env file, and start the two big services that everything else needs: vLLM (the language model) and OpenSearch (the search engine).

SECTION 2B.4 - Install system tools and learn tmux (jobs that survive disconnects)

WHERE: VS Code Terminal, folder ~/querymesh

GOAL: tmux, git, jq and unzip installed; you can start, leave and re-enter a tmux session.

Step 1. Install the tools:

sudo apt-get update && sudo apt-get install -y tmux git unzip jq

You should see: the last lines say "Setting up tmux ..." or "tmux is already the newest version".

Step 2. Start a practice tmux session:

tmux new -s practice

Step 3. In the tmux session type a long-running command:

for i in $(seq 1 300); do echo "tick $i"; sleep 1; done

Step 4. Detach (leave it running): press Ctrl+B, release both keys, then press D.

You should see: "[detached (from session practice)]" and your normal prompt.

Step 5. List sessions:

tmux ls

You should see: practice: 1 windows ...

Step 6. Re-attach:

tmux attach -t practice

You should see: the ticks still counting.

Step 7. Stop the loop with Ctrl+C.

Step 8. Type exit and press Enter to close the session.

Key or commandMeaning
tmux new -s NAMEstart a new session called NAME
Ctrl+B then Ddetach: leave the session running in the background
tmux lslist running sessions
tmux attach -t NAMEgo back into a session
exit (inside tmux)close the session
jqa tool that pretty-prints and filters JSON answers from APIs

Why it matters: Airflow and the five agents run for hours. If your laptop sleeps or Wi-Fi drops, a normal terminal kills them; a tmux session keeps them running on the GPU computer.

CHECKPOINT: you detached and re-attached once.

"""Every setting QueryMesh needs, read from environment variables (the .env file)."""
import os

from dotenv import load_dotenv

load_dotenv()  # copies the lines of .env into os.environ (real env vars win)


def env(name: str, default: str = "") -> str:
    return os.getenv(name, default)


# Search engine (OpenSearch)
OPENSEARCH_URL = env("OPENSEARCH_URL", "http://localhost:9200")
INDEX_NAME = env("INDEX_NAME", "arxiv-chunks")
SEARCH_PIPELINE = env("SEARCH_PIPELINE", "querymesh-rrf")

# Embeddings (Jina AI)
JINA_API_KEY = env("JINA_API_KEY")
EMBED_MODEL = env("EMBED_MODEL", "jina-embeddings-v5-text-small")
EMBED_DIM = int(env("EMBED_DIM", "1024"))

# Language model (vLLM on Hyperstack, OpenAI-compatible)
LLM_BASE_URL = env("LLM_BASE_URL", "http://localhost:8000/v1")
LLM_API_KEY = env("LLM_API_KEY", "EMPTY")
LLM_MODEL = env("LLM_MODEL", "qwen3-4b")

# Cache (Upstash Redis)
REDIS_URL = env("REDIS_URL")
CACHE_TTL_SECONDS = int(env("CACHE_TTL_SECONDS", "86400"))

# Paper storage (S3 on FakeCloud or AWS). Empty = do not upload.
PAPERS_BUCKET = env("PAPERS_BUCKET")

# Agents: base URLs of the five agent servers, comma separated
AGENT_URLS = [u.strip() for u in env("AGENT_URLS").split(",") if u.strip()]
WORKER_MODE = env("WORKER_MODE", "local")  # local = in-process, remote = MCP over SSE

# API security (JWT)
JWT_SECRET = env("JWT_SECRET", "change-me-please-use-a-long-random-string")
JWT_MINUTES = int(env("JWT_MINUTES", "60"))
API_USERNAME = env("API_USERNAME", "admin")
API_PASSWORD = env("API_PASSWORD", "admin")
API_URL = env("API_URL", "http://localhost:8090")

# Telegram
TELEGRAM_BOT_TOKEN = env("TELEGRAM_BOT_TOKEN")

# Agentic RAG limits
MIN_RELEVANT = int(env("MIN_RELEVANT", "2"))
MAX_RETRIEVALS = int(env("MAX_RETRIEVALS", "2"))
MAX_GENERATIONS = int(env("MAX_GENERATIONS", "2"))
TOP_K = int(env("TOP_K", "8"))

#!/usr/bin/env bash
# Start OpenSearch (search engine) on the VM, port 9200, data kept in a Docker volume.
set -euo pipefail
sudo sysctl -w vm.max_map_count=262144   # OpenSearch refuses to start without this

docker rm -f opensearch 2>/dev/null || true
docker run -d --name opensearch --restart unless-stopped \
  -p 127.0.0.1:9200:9200 -p 172.17.0.1:9200:9200 \
  -e discovery.type=single-node \
  -e DISABLE_SECURITY_PLUGIN=true \
  -e DISABLE_INSTALL_DEMO_CONFIG=true \
  -e OPENSEARCH_JAVA_OPTS="-Xms2g -Xmx2g" \
  -v opensearch-data:/usr/share/opensearch/data \
  opensearchproject/opensearch:3.9.0
echo "OpenSearch is starting. Test in 30 seconds with: curl -s localhost:9200"
